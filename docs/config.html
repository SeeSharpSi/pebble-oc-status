OpenCode Status

Settings for the Pebble watchapp. Save, then open the app on the watch.

Plugin polling

Plugin default uses the OpenCode plugin's own refresh intervals.

Show only active/action

Hides read or idle sessions. Running sessions, unread replies, questions, and permission requests stay visible.

Mark read after

On app load, unread replies older than this are marked read automatically. Permission and question requests are never dismissed.

Subagents

Choose how subagents appear in the watch list.

Number and Hide also hide subagent questions and permission requests from the watch list. They are not forwarded to the parent session. Open OpenCode on your phone or computer to respond.

Number requires an updated OpenCode plugin that exposes parent and root session IDs.

Canned replies

One per line, up to 8. Short-press Select on a reply to choose one; long-press to dictate.
