OpenCode Status

Settings for the Pebble watchapp. Save, then open the app on the watch.

Plugin polling

Plugin default uses the OpenCode plugin's own refresh intervals.

Show only active/action

Hides read or idle sessions. Running sessions, unread replies, questions, and permission requests stay visible.

Mark read after

On app load, unread replies older than this are marked read automatically. Permission and question requests are never dismissed.
